python main.py -i ./input/small_movie.tif -t ./input/template.tif -fo 9 -fs 6 -tx 41 -ty 21


################# Checking the results

correct_segmentation --path_img ./output/2024-03-20_14-02-01/split_data/23/midap/cut_im --path_seg ./output/2024-03-20_14-02-01/split_data/23/midap/seg_im

Nadia's advice:
run pipeline in full first then only after exclude steps. Excluding steps might not work on the first go because some steps expect a result from previous steps.


The pipeline needs a template of the exact trap orientation in the movie you are processing, so you need to generate a fresh one each time you ananlyse a new movie.
